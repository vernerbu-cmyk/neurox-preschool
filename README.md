# NeuroX: Подготовка к школе

**Самостоятельный сайт и будущий Android-проект** для детей 5–7 лет. Здесь 19 тренажёров, четыре направления и утверждённое игровое меню с оригинальной белкой и синим карандашом.

Это **не подраздел** основного NeuroX. В этой сборке нет ссылок на другие разделы большого сайта.

## Публикация в GitVerse

1. Создайте отдельный репозиторий, например `neurox-school` или `neurox-preschool`.
2. Распакуйте ZIP и загрузите его содержимое в **корень** репозитория. `index.html` должен находиться в корне.
3. Включите публикацию статического сайта через GitVerse Pages в настройках репозитория, используя актуальные параметры GitVerse для вашего аккаунта.
4. Проверьте стартовую страницу, переходы между четырьмя направлениями и запуск игр.

## Структура самостоятельного продукта

- `index.html` — **главная страница всего приложения**, не страница подраздела.
- `games/` — 19 тренажёров с сохранённой логикой и отдельными адресами.
- `assets/` — локальные ресурсы и **четыре направления** бокового меню.
- `manifest.webmanifest`, `assets/icons/` — задел для установки приложения.
- `.nojekyll` — файл для публикации без преобразования HTML.

В игровых страницах предусмотрены ссылки «Все игры» / возврат в корневое меню. Все пути относительны, поэтому проект может работать в корне сайта или в подпапке GitVerse Pages.

## Известные ограничения

- «Кристальная пещера» взята из доступного базового архива. Если у вас есть более свежая переработанная версия, её нужно подставить отдельно.
- Сохранение данных пока реализовано в отдельных играх, общего детского профиля и синхронизации результатов нет.
- Для мобильного приложения потребуется дополнительная проверка WebView, офлайн-ресурсов, Android Back и локального хранения.
- На оригинальном основном репозитории NeuroX ничего не изменено.
