# Слоголаз — проект Android Studio (v13)

Полноценный Android-проект детской игры **«Слоголаз»**: словарь и сцены из версии v12 + исправленный фильтр случайных слоговых сочетаний из v13.

## Как открыть
1. Распакуйте `Slogolaz-AndroidStudio-v13.zip` в отдельную папку.
2. Запустите **Android Studio → Open** и выберите папку `Slogolaz-AndroidStudio-v13` (ту, где находятся `settings.gradle`, `gradlew` и папка `app`).
3. Дождитесь **Gradle Sync**. Для первой сборки потребуется интернет, Android SDK Platform 35 и JDK 17 (Android Studio предложит установку недостающих компонентов).
4. Подключите телефон с разрешённой отладкой по USB и нажмите **Run**, либо выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Готовый отладочный APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Состав проекта
- `app/src/main/assets/index.html` — автономная игра «Слоголаз» v13: режимы, темы, словарь, исправленный фильтр.
- `app/src/main/java/ru/neurox/slogolaz/MainActivity.java` — Android WebView-оболочка, работающая без адресной строки.
- `app/src/main/res/mipmap-*/` и `drawable-nodpi/` — **готовые** значки приложения (гора, флажок, «СО»), включая адаптивную иконку Android.
- `icon.svg`, `generate_icons.py` — исходники значка на случай редактирования; **Python для открытия и сборки проекта не нужен**.
- `gradlew`, `gradlew.bat`, `gradle/wrapper/` — Gradle Wrapper 8.10.2 (включая JAR).
- `app/build.gradle` — настройки Android: `applicationId ru.neurox.slogolaz`, `versionCode 13`, `versionName 1.13`, `minSdk 24`.

## Важные особенности
- Все игровые файлы встроены в приложение; для **самой игры интернет не нужен**.
- Не запрашиваются камера, микрофон, геолокация и разрешение на доступ к интернету.
- Настройки сохраняются в локальном хранилище Android WebView.
- Отладочные APK, собранные на разных компьютерах или в GitHub Actions, могут быть подписаны **разными ключами**. Поэтому установка нового APK поверх уже установленного из другого источника может завершиться ошибкой подписи. **Не удаляйте старую версию, пока не сохраните нужные данные:** удаление может стереть локальные настройки.
- Для распространения обновлений лучше настроить собственную постоянную подпись через **Build → Generate Signed Bundle / APK** и хранить ключ в безопасном месте.
